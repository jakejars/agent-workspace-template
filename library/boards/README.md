# Boards

Playlists, not homes. A board gathers topics, examples, and specimens
that already exist under one through-line — "interfaces that stay calm
under load" — with **one line per entry saying why it made the cut**.

**Link, never copy.** Content stays in its canonical home; a board
holds pointers and the reason for the gathering. The moment a board
holds a fact nothing else holds, the fact is misfiled — move it to a
topic and link it back.

## Rules

- A board is `status: draft` at most until it has been used to answer
  something. It is never cited as knowledge; cite the entry it points
  to.
- A board is rewritten in place. Entries join and leave as the
  through-line sharpens; nothing about that is history worth keeping.
- A through-line that only ever gathers two entries is a `related:`
  edge between them, not a board.
- A board never justifies a new category. It is the cheap alternative
  to one.

## Boards here

None. The template ships the shape, not the curation — boards come from
material you actually have.

A board is small enough to write from this page: one file,
`library/boards/<through-line>.md`, `type: board`, a description whose
"Use when" names the through-line, then a list of links with a line
each. List it in this section in the same edit; an unlisted board is an
orphan and the loop check says so.
