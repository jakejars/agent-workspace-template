# Governance

The workspace entrance states authority boundaries. The current user request
supplies task scope; this chamber holds standing policy and durable approvals.

| File | Owns |
|---|---|
| [autonomy.md](autonomy.md) | Effect classes and existing authorization |
| [policies.md](policies.md) | Standard workflow and optional audit profile |
| [boundaries.md](boundaries.md) | Confidentiality and the literal-term scrub |
| [approvals/README.md](approvals/README.md) | Scoped, sourced approval records |

An agent can record authorization the human has actually given. It cannot
approve its own proposal, manufacture consent, or turn silence into approval.
Task wording that explicitly asks for an action supplies authority for that
action within its scope; forms record this authority, they do not create it.

Human-owned policies change only by human direction. Finish useful preparation
before requesting a missing decision. Keep strict external-effect and privacy
controls in both standard and audit profiles.
