# Seam: library

Linked library: `<<LIBRARY_PATH>>`. Empty closes the seam; knowledge remains in
`40_knowledge/`.

## What crosses

- In, on demand only: generated catalog for routing; 2–3 cue-matched entries;
  deeper explicit links; typed citations (`draft` with caveat or `mature`);
  source-citing starters.
- Out: one-file inbox captures and proposed diffs. Library promotion remains
  local to the library.

## Direction

In is pull-only data, never execution or boot. Out is class-B capture/proposal,
never canonical write.

## Inspect point

- Using file names source topic for citations/starters.
- Library inbox shows outbound captures.
- Library validator proves its content; workspace does not revalidate it.

## Control point

- Path token; unset closes.
- Status gates citation.
- Rights records gate media; specimen media never leaves the library.
- Only cross-workspace reusable knowledge crosses out.

## What never crosses

- Principal data, journals, runs, secrets, or never-share content.
- Specimen media outward.
- Bytes without a rights row inward.
